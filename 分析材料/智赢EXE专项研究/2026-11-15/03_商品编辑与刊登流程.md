> 上游接 `02_商品采集库与数据流.md`；下游对照 `05_UnaSeller可借鉴功能清单.md`。
> 全部为静态证据。**OBSERVED** = 资源/类型/方法名直接可见；**INFERRED** = 由命名与结构拼接的业务顺序；**UNKNOWN** = 无证据。

## 0. 结论速览

| 结论 | 等级 |
|---|---|
| 采集商品不是「直接刊登」，中间有 **草稿箱 → 编辑 → 审核/导入主库 → 多店上架** 的多级缓冲 | **INFERRED**（由中文资源与方法名拼接） |
| 编辑能力覆盖：标题、图片、多规格变体、SKU/库存、价格、分类属性、描述、五点卖点 | **OBSERVED**（功能标识） |
| 「普通描述」与「五点卖点」在编辑层同样是两套独立控件/模板 | **OBSERVED** |
| Mercado Libre 相关代码集中在 `ZYing.User.dll` 的 `Channel.Meli` / `Detail.Meli` / `Dialog.DMeli` 与 `ZYing.Work.dll` 的 `ZYing.Mercadolibre` / `ZYing.Meli.Model` | **OBSERVED** |
| 存在「一个商品分配到多个店铺/国家站点」的功能标识（多店上架、多选店铺、国家站点、分类映射国家） | **OBSERVED**（标识）/ **INFERRED**（分配规则） |
| 存在跨境 CBT/UP 与站点 Item 的区分线索（`chkCBT` / `OnlyCBT` / `MeliItemInfo` / `UpdateMarketItem`），但**数据模型无法确认** | **INFERRED** + **UNKNOWN** |
| 客户端内含有平台 API 直连代码（Mercado Libre / Amazon / eBay / Lazada 等） | **OBSERVED** |

### 1.1 直接证据（`ZYing.User.dll` 中文资源与标识符）

### 3.3 跨境 UP/CBT 商品 vs 站点 Item

| 线索 | 位置 | 判断 |
|---|---|---|
| `chkCBT`、`OnlyCBT` | `ZYing.User.dll` | **INFERRED**：UI 存在「仅看跨境 CBT」过滤开关 |
| `MeliItemInfo`、`UpdateMarketItem`、`PublishMartketResult`、`itemid`、`GetItemIdList`、`itemIds` | `ZYing.Work.dll` / `ZYing.User.dll` | **OBSERVED**：存在平台 Item 级对象与刊登结果对象 |
| `MeliLocalLogList` / `MeliLocalLogDetail` / `本土店铺不采集` | `ZYing.User.dll` / `ZYing.Work.dll` | **INFERRED**：区分本土店与跨境店的日志/视图 |
| `ZYing.Detail.Sale` / `EMarketSale` / `BaseMarketData\`1` | `ZYing.User.dll` | **INFERRED**：存在「商品资料」与「刊登资料」两层数据 |

**结论（INFERRED）**：智赢区分「跨境/UP 商品资料」与「各站点 Item 刊登实例」，且 UI 层有 CBT 过滤；但**没有拿到状态枚举、表结构或接口 DTO**，因此具体字段、映射关系与生命周期 **UNKNOWN**。
Una Seller 的 `FOUNDATION.md` / `ERP-MVP.md` 已把 CBT UP 与 MLM/MLB/MLA 映射列为后续模块，本轮不复制其实现。

> **合规边界**：本轮只记录「存在平台 API 调用与请求签名机制」这一用途，未输出任何 Token、密钥、签名算法或私有协议实现，也未尝试复用。

## 5. 与 Una Seller 首版的关系（简版，详见 `05`）

| 智赢环节 | 对 Una Seller 的意义 | 建议 |
|---|---|---|
| 采集库 → 草稿箱 → 审核 → 主库 → 多店上架 | 属于成熟商业 ERP 的多级工作流 | **首版不做**。`ERP-MVP.md` 首版只到「采集库 + 详情」，刊登/OAuth/多店铺属于后续阶段 |
| 描述 / 五点卖点独立、图片与变体分离 | 直接对应首版验收项 | **必须借鉴为数据契约要求**，实现独立编写 |
| 变体字典 / 词替换 / 批量改价 / 图片差异处理 | 提升编辑效率的运营工具 | **P2 以后再评估** |
| 客户端内置平台 API 与 CEF 采集器 | 与「插件人工采集 + Token 只在服务端」的既定边界冲突 | **不采用** |
