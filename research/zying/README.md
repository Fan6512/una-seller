# 竞品研究摘要（历史）

此目录仅保留一份人类可读摘要，供开发新成员理解需求来源；**不是功能规格、SDK、第三方协议实现依据**。

2026-10 至 2026-11 研究了竞品桌面 ERP 与浏览器采集工作流，归纳出三个对 Una Seller 有用的用户操作：
1. 浏览器人工点击采集来源商品，保留原始图片、描述、卖点以及已经实际发现的变体。
2. 在桌面采集箱查看、筛选、核对来源数据；将来源商品与之后独立编辑的自有商品区分。
3. 商品准备妥当后，通过官方 Mercado Libre 接口按账号与站点发布，逐站点核实结果。

**现行需求**以 [浏览器采集 MVP](../../docs/product/BROWSER-COLLECTION-PLUGIN-MVP.md)、[商品工作流](../../docs/product/PRODUCT-WORKFLOW-AND-EDITOR.md) 和 [Delivery](../../docs/architecture/DELIVERY.md) 为准。

原始反编译文件、第三方插件完整目录、运行时扫描及派生脚本**不再放在公开仓库的当前文件树**。历史 Git 提交仍可追踪以前做过哪些调查；这不等同于删除公开 Git 历史中的副本。避免在公开仓库存放第三方源码、可能包含私有实现或访问凭据的材料。
