## 注意事项

- 大量脚本仍使用本机 `E:/美客多逆向` 绝对路径，且原始 `decrypted/` 目录未入库：仅有 Git 克隆时不能完整再生派生清单；迁移不代表问题已解决。
- 报告中 `file:///` 链接只在原本机证据目录可用，远程仓库无法直接点开。
- 研究脚本包含部分第三方解密常量/派生信息，后续应进行专门许可、安全与敏感性复核；当前目录迁移未改变这些字节。
- 不提交目标程序二进制（`ZInstall.exe`）、账号凭据或第三方 Cookie。
- **第三方反编译源码、内存转储扫描与程序集元数据按明确决策入库**（2026-11-15），用于交叉核对分析报告的准确性、评估是否有更优实现方式。这类内容仅供**研究比对**，不得作为源码复用、SDK 或协议契约；引用时须标注来源为第三方反编译产物。
- 本目录内容为公开仓库托管，包含第三方代码片段，存在被权利人主张许可/版权的可能；如收到相关通知，应优先下架对应目录而非整个仓库。
- 任何反编译结论都只能算静态观察；官方平台能力必须独立按官方文档与受控账号验证。
