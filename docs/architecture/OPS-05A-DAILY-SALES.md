# OPS-05A 每日缓存商品销售额

独立开发切片，不依赖 CBT-02，不修改生产。使用既有 owner-scoped operations-summary GET 和本地订单缓存；不调用官方接口、不增加轮询或迁移。

按服务器生成的北京时间（固定 UTC+8）自然日 date_created，半开区间 [00:00, 次日00:00)。这是当日创建且当前 paid 的商品销售额，不是付款到账日、结算日或实际利润。每个订单用现有完整作用域主键、EXISTS 映射匹配，不重复计算映射。沿用 orderSalesAmountUSD，只统计明确 USD 商品行的数量×单价；绝不使用可能错标币种的 total_amount，不包括运费/税/退款金额，不混算其他币种。部分退款及全额退款先整体排除并披露数量；取消和其他状态独立计数。歧义商品行、空商品行、非 USD 等计入待核实；只显示可核实订单的缓存小计和分母，不把小计当作完整平台销量。无有效订单、无授权、超过安全查询上限显示不可用而非假零。所有金额精确求和后舍入一次。限定每次最多10000笔缓存订单，超过时不显示金额；后续按实际规模决定索引或聚合。复用30秒本地轮询。

FIN-02 仍需可信实际结算及退款证据、逐单实际成本和汇率。无真实来源不得用订单总额、税基、fee.net、刊登净收益推算利润。今日利润保持待核算，不能用销售额乘利润率。真实账单样本验证后单独完成。

测试仅覆盖核心日期边界、有效 USD 商品行、币种缺失/错误、退款取消、授权范围及不使用原始订单金额。CI 待执行。
