# WH-06 ACK 延迟修复、隔离实测与联合部署预案

## 验收基线

2026-11-26 23:57:25（北京），真实货件对应窗口的五字段日志为 HTTP/上游 503/503，耗时 351/351 毫秒。数据库有真实货件收件和写回证据，五字段日志无法逐请求关联事务。真实 HTTP 200 ACK 仍未验收。[生产夜间回执](NIGHT-PREFLIGHT-20261127.md)

官方通知要求 HTTP 200 在 500 毫秒内返回。候选保持 400 毫秒的请求体和数据库总预算。只有同步事务提交获确认后才返回 200。保留全局事务准入锁、作用域锁、容量、去重和 generation 规则，以及原并发和请求体限制、入口白名单、令牌、限流和日志脱敏。[Global Selling 通知规范](https://global-selling.mercadolibre.com/devsite/receive-notifications)

## 隔离 PostgreSQL 17.11 实测

生产主机到生产 session pooler 的只读 TLS 校验连接内执行 20 次 `SELECT 1`，p50 58.9ms、p95 59.4ms。另在独立 Docker network namespace 运行 PG 17.11，TLS `verify-full`、磁盘 fsync 和同步提交均启用，使用 3 连接池及 550 条合成回执。仅对该隔离数据库 TCP 加入双向各 29ms 的延迟，实测查询 p50 58.4ms。HTTP 请求只发往隔离回环，独立数据库连接在 200 后立即读取并验证回执和作业。没有对生产注入通知。测试覆盖数据库链路延迟，实际 Supavisor 行为、广域公网、官方源和生产负载有待获批后自然样本验收。

原候选首次执行时，准备语句令 `admission` 和 `scope` 各耗约 117–118ms，随后在容量查询用尽预算。暖连接的 BEGIN、准入锁、作用域、容量去重、写入、提交各用约一个 RTT。优化后实时路径改用每次一个往返的参数化协议，合并作用域、容量去重及写入为一个 SQL。事务先取得原准入锁，后续 SQL 再取快照。共享写入规则仍由同一 SQL 定义，补偿和回放继续使用各自的已锁定作用域和连接原有协议。暖连接日志通常为获取 0ms、BEGIN 58ms、准入 58ms、回执 SQL 61–66ms、提交 58ms。并发时单次准入约 120ms，其余阶段同量级。真实连接断开后的重建、持锁到期和 COMMIT 结果不明均保留失败重试语义。400ms 总预算保持。

另通过现有 PG 定向测试，覆盖 6 并发的重复与不同通知、所有权与容量、重复作业 generation、准入锁和写入锁。完全冷池仍存在失败窗口，不能据本回执宣称所有 500ms 场景已通过。若自然样本集中失败在连接获取，先核实池恢复、空闲连接和连接中断，再单独评估预热配置。

## #115 / #116 / #117 统一部署预案

1. 分别获批后固定三个 PR 的批准提交和最终 main。#115 已合并；#116 保持本轮复审版本；#117 以本轮最终 CI 和测量回执为准。基于最终合并源码构建 Linux amd64，记录 SHA-256、工作树状态及回滚二进制的 SHA-256，核对来源 ID 与运行文件。Windows 客户端经现有 QA 流程由负责人手工验证。
2. 复用已通过的加密备份恢复、PG 17.11 原生 0021/0022 两次、RLS/授权和 Nginx 路由预检。审批窗口开始另取新加密备份；重新核对目标、恢复证据、生产当前 0014–0020 和候选迁移、旧回滚文件。#116 和 #117 无新增迁移。用固定候选在隔离环境复验。
3. 获批后执行 0021/0022 并复核私有表/RLS/恢复函数授权。原子切换 API，只重启 UNA Seller。以现有站点配置为底稿，验证只增加刊登精确路由 60 秒并保持产品箱 20 秒，移除通用前缀的 `^~` 以确保精确规则可命中。语法、差异、权限及回滚副本齐全后才 reload。保留 Webhook 白名单、令牌、限流、两主题、脱敏日志、OPS-03 自动补偿和禁用历史回放。保持 CBT-02 暂停。
4. 核对健康、匿名鉴权、版本哈希、运营摘要、本地缓存范围、队列、冷却和断点。仅用后续自然的官方投递同时观察五字段日志、入库和消费。HTTP 200 且总耗时低于 500ms 才验收真实 ACK。Payout 核账和 Windows 验收继续各自门禁。
5. 故障时验证并原子恢复预留二进制和站点配置，恢复同一服务后复验 API、Webhook 和运营队列。已加的数据库表及真实业务数据保留。数据库恢复独立审批并评估备份之后的数据。本回执仅准备方案，没有执行合并或生产变更。
