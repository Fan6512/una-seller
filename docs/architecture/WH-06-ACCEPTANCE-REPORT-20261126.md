# WH-06 阶段 A 最小验收

日期为 2026-11-26，适用于 [PR #106](https://github.com/Fan6512/una-seller/pull/106)。

## 隔离迁移与回放

- 在回环 PG 17.12 的独立新库应用 0001–0019，确认断点表尚未存在。随后连续执行 0020 两次，执行器遇 SQL 错误即退出。两次均确认断点主键为应用、主题、授权店铺，RLS 启用，收件箱来源约束唯一。
- 原实现用 OWNER/STORE 选择请求凭据，offset 却在应用和主题下共享。如果官方按凭据返回不同记录，第二个店铺可能从第一个店铺的 offset 开始，跳过首页。0020 和回放事务现按授权店铺隔离断点。OWNER 与 STORE 仍由现有授权查询校验，通知仍按事件身份解析归属和去重。
- 隔离 PG 回归通过。第一家店铺推进至 offset 8，第二家仍从 0 开始。未知卖家使整页回滚，第一家继续从 8 恢复。短页回零，重复事件不增加收据或作业。归一化与 TokenCipher 现有定向测试通过。
- 0020 属于尚未发布的阶段 A 迁移。上述验收使用 0019 基线，全程未修改生产数据库。

## 生产授权只读诊断

探针使用项目原生 TokenCipher 与 tokenAAD，从运行中的服务进程读取密钥配置，在只读数据库事务内核验唯一连接。运行时密钥格式与合成数据往返通过。Access、Refresh 密文均为版本 1，使用持久化 owner、父卖家和各自用途构造 AAD 后解密成功。Access Token 已过期，Refresh Token 的官方有效性尚未验证。旧探针报出的认证失败未在原生实现中复现，旧探针与当前结果不同的具体原因未确认。

探针未输出凭据、密钥、密文、卖家或用户标识。生产未部署、未迁移、未启用 Webhook 或历史回放、未修改官方订阅，未刷新、轮换、删除 Token，也未解除授权或修改密钥。

## 阶段 B

先在单独授权窗口内对该连接走既有应用续期流程。若官方拒绝续期，再由店主重新授权。验证连接可读取官方只读接口后，按主题复核 missed_feeds 的权限、分页和留存。公网 ACK、Nginx 实机和官方订阅验收按阶段单独推进。真实 missed_feeds、公网 ACK 压测和 Nginx 实机演练属于阶段 B。
