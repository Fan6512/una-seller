## Message conversation reminder rule

Group available message observations by owner/store/parent/child/site/Pack. A conversation is pending only when its latest observed incoming message has no strictly later available outgoing message. A later observed seller reply clears the local work item; a later buyer message reopens it once per conversation, not once per message. Use provider creation time, not notification arrival time, and keep equal-time ambiguity pending. Do not expire unreplied work after seven days. Only observed available messages with valid Pack IDs count; no observed eligible conversation is null. Latest activity collapses messages into a conversation and uses latest provider message creation time. This is local reply/processing inference, not official unread status, and requires outgoing message sync to see replies made elsewhere.
