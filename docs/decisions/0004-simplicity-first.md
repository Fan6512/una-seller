# ADR-0004：第一性原理、简单优先、暂不商业化

- 日期：2026-10-26
- 状态：**Accepted**
- 适用范围：Una Seller 全部新需求与架构决策
- 优先级：若与早期面向成熟 SaaS 的技术规划冲突，本决策优先。

## 核心决定

**只解决真实问题，不为了设计而设计。** 每个新功能、新框架、新服务先确认真实使用场景和最小可用方案；无法证明必要性则延后。优先少依赖、少服务、少抽象、小步提交、可实际验收。

基础安全不能砍：HTTPS、OAuth state、Token 保密、访问鉴权、写操作的目标与输入校验；但是不提前做零信任、复杂 RBAC、安全中心、重型风控和大型审计平台。

**当前明确不做**：充值、支付、套餐、订阅、额度计费、商业 SaaS 管理后台，以及纯粹为未来商业化准备的多租户基础设施。

里程碑仅 M0（能跑）→ M1（商品）→ M2（AI 有用）→ M3（按需运营）。原 M4 商业化冻结，只有新的商业化决定才能重新启用。

## 进入复杂架构的门槛

要求提供：真实问题、目前简单方案的失败证据、更简单替代方案的评估、维护成本，以及拆除/回退路径。无证据先不加。
