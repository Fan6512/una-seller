# ADR-0003：官方平台适配与 AI Tool 边界

- 日期：2026-10-26
- 状态：**Accepted as design baseline; implementation pending**

## 决策

产品只调用 Mercado Libre 官方 API；竞品静态研究仅作为业务功能和用户体验参考，不引用智赢反编译代码/私有协议/平台 DOM 自动化。

CBT UP 全局主数据与各国 site listing、卖家身份分离；产品/订单/售后等领域不直接依赖 HTTP 路径或平台 DTO。适配层负责认证、请求、限流、错误和 DTO 转换，正式文档与实测建立能力矩阵。

AI 调用经模型适配器（可连 UnaAPI），但 ERP 自持数据、身份、权限、审批与审计；不与 UnaAPI 共用账务或业务库。模型工具分只读、建议和受控写；高风险变更人工审核，并通过统一领域命令执行。

## 非目标

不依赖官方 MCP 作为唯一 ERP 入口；可未来复用业务工具开放 MCP，但不另写一套订单/商品服务。
不让客户端或 AI 获取平台 Token，不让模型执行任意 HTTP/SQL，不绕过审批。

## 验证

建立官方 API 端点/Scope/站点/回读能力表。测试 Token 轮换、站点 Seller 映射、不同租户越权、AI 提示注入、写命令超时后回读，以及跨国家标题/语言规则。
