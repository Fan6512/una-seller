# ADR-0002：PostgreSQL 事实源 + 持久任务 + 渐进同步

- 日期：2026-10-26
- 状态：**Accepted as design baseline; implementation pending**

## 决策

PostgreSQL 保存租户、平台镜像、ERP 自有数据、审计及任务持久记录。客户端 SQLite 只缓存必要数据和草稿；SQLCipher 在通过双平台打包、密钥及迁移验证后采用。任务优先选择与 PostgreSQL 事务协同的持久队列（River 等是候选，许可证/运维/能力需评审）。

Redis、Event Bus、独立数据仓库及完整离线双向同步引擎均延后。

## 边界

使用精确金额；在业务命令层实现去重、状态机、审批、外部回读和未知结果恢复。不可把 PostgreSQL 中的唯一任务约束误认为 Mercado Libre 外部 API exactly-once。
设备吊销可立即拒绝服务端会话，但离线缓存要到设备恢复连接才能按设计清理；不要对外承诺离线即时远程擦除。
后续增量同步游标采用提交顺序一致的机制，不直接拿数据库 sequence 的分配顺序作为提交顺序。

## 代价与复核触发器

任务吞吐和多业务优先级升级时，依据 P95 延迟、429、队列积压、故障隔离的实际证据决定是否引入 Redis/独立调度或拆服务。离线多端修改成为硬需求时，再评审 outbox、版本冲突与变更日志方案。
