# ADR-0001：桌面跨平台与单体优先；M0 后端采用 Go

- 日期：2026-10-26
- 更新：2026-10-26（简化修订）
- 状态：**已更新：桌面技术不变，M0 Go API 作为当前选型；具体部署见 ADR-0005。**
- 适用：Una Seller 自用优先、只支持 Mercado Libre。

## 决策

- Windows/macOS 客户端采用 Tauri 2 + React + TypeScript (strict)，仅保留必要 Rust 原生代码。
- 服务端从**一个 Go HTTP 应用**开始，优先标准库和最少依赖；在现有 Ubuntu 2C4G 服务器上部署。用户已明确选择该部署路径，M0-01 Go 健康检查代码已提交待实机验收。
- 初期不拆微服务，不创建独立 AI 进程、独立身份系统、事件总线。
- 是否提前使用 OpenAPI SDK 生成依据重复类型与契约变化成本决定；最初可使用小型、明确定义的接口。

## 理由

跨平台是确定的硬需求；性能瓶颈还没有实测。单人早期研发最重要的是简单、可测、可部署，不是构建复杂技术栈。

## 选型验收

以 Go 完成桌面连通、Nginx HTTPS、Supabase 最小数据写读与后续 OAuth 的真实验证。**尚未完成 Go 与 TypeScript 的正式实测对比，不声称性能比较已通过**；目前由明确的自用部署决策取代事前双技术试验，遇到证据充分的维护问题再审视，不重复开发两套后端。
