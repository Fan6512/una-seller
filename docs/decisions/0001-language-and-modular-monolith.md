# ADR-0001：桌面跨平台与单体优先；后端语言保留验证选择

- 日期：2026-10-26
- 更新：2026-10-26（简化修订）
- 状态：**桌面技术确定；后端语言待 M0 极小验证，替代原先直接锁定 Go 的决定。**
- 适用：Una Seller 自用优先、只支持 Mercado Libre。

## 决策

- Windows/macOS 客户端采用 Tauri 2 + React + TypeScript (strict)，仅保留必要 Rust 原生代码。
- 服务端从**一个简单 HTTP 应用**开始。Go 与 TypeScript/Fastify 均可行；M0 以端到端搭建、部署、依赖量和实际维护成本决定，不因假想吞吐提前混用技术。
- 初期不拆微服务，不创建独立 AI 进程、独立身份系统、事件总线。
- 是否提前使用 OpenAPI SDK 生成依据重复类型与契约变化成本决定；最初可使用小型、明确定义的接口。

## 理由

跨平台是确定的硬需求；性能瓶颈还没有实测。单人早期研发最重要的是简单、可测、可部署，不是构建复杂技术栈。

## 选型验收

创建一个桌面页面请求后端 API 并访问最小数据表，比较 Go 与 TypeScript 路线：总配置文件、依赖和开发速度，跨平台工具链、测试/发布难度。记录结果后再锁定后端，不重复开发两套正式实现。
